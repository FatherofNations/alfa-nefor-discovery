# Сверка таблицы ленты операций

Фрейм `59:19781` охватывает таблицу ленты с днями, строками и кнопкой «Показать ещё». Заголовок секции, фильтры и аналитика находятся вне этого узла. Использованы удалённый Figma MCP и дерево из `table.xml`.

Выбранный чекбокс `public/assets/figma/ops-table-checkbox-checked.svg` — SVG `imgContent` (`8e3fd.svg`) из `Checkbox24` в design context этого узла. У исходника размер 20×20. Слот 24×24 и инсет 2 px подтверждены `checkbox.xml`.

Измерение Chrome нормализовано относительно начала таблицы. Для сверки геометрии через DOM в отдельном прогоне подставлены два дня и четыре строки из макета. Сравнено 64/64 бокса с нулевым отклонением по `qa/operations-table.geometry.json`. На декабрьских данных — 9 строк без переполнений, до правки их было 7. Поиск сузил список до одной строки и вернул девять после очистки. Выбор и снятие выбора через чекбокс прошли, SVG загрузился, ошибок консоли и битых картинок не было.

Фрейм высотой 817 px в Figma клипируется родителем. Нативный доступный кадр `reference.png` имеет размер 972×266. `local.png` — тот же участок в Chrome с примерами Figma. Средняя |Δ| 2,95, 2,53% пикселей выше порога 32. У второй суммы ширина чернил меньше на 7 px, правая граница отличается на 1 px. Размер и позиция колонки совпадают. Разделитель и многоточие не дали отличий выше 32. При поэлементной сверке выше этого порога остались пиксели на краях чекбокса, логотипа и текстового бейджа. Нижние строки и кнопка сверены по метаданным, CSS и DOM в Chrome.
